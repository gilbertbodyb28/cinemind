# Changelog

All notable changes to CineMind are documented here. Git tags are the release source of truth.

## Unreleased

- Added public-project documentation, contribution rules, security policy and community-post draft.
- Added release-readiness checks and CI scaffolding.
- Documented demo mode, architecture, local setup and known limitations.

## 0.1.0 — release candidate, not published

This section is prepared for the first stable GitHub release. It must not be described as released until a clean commit is tagged and the GitHub Release is actually published.

### Included

- Self-hosted React and FastAPI application.
- MongoDB-backed sessions, taste data, recommendations, jobs, requests and saved items.
- Demo seed data for exploring the product without connected providers.
- Optional TMDb, Trakt, Simkl, Plex, AniList, Ollama and MediaManager integrations.

### Release blockers

- Clean-install verification on a fresh machine.
- Green CI on the chosen public baseline.
- Final security and third-party-service review.
- At least one external installation and one independently reported issue or documentation improvement.
