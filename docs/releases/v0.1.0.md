# CineMind v0.1.0 release notes

Status: prepared locally; not tagged or published.

## Summary

CineMind is a self-hosted movie and TV discovery companion with optional provider history, TMDb enrichment, local Ollama assistance, explainable recommendation filters and MediaManager approval actions.

## Included

- React frontend and FastAPI backend.
- MongoDB-backed sessions, taste signals, recommendations, jobs, requests and saved results.
- Clearly marked demo mode.
- Optional TMDb, Trakt, Simkl, Plex, AniList, Ollama and MediaManager integrations.
- Contributor, security, conduct and issue-reporting documentation.

## Known limitations

- The project has not had an independent security audit.
- Some integrations require provider credentials and their own terms of service.
- Some tests are integration-oriented and need MongoDB or fixtures.
- macOS/NAS scripts are environment-specific.
- No adoption, user, contributor or production-readiness claim is made by this release note.

## Publish gate

Do not tag or publish until the release commit has green CI, a clean-install verification, a completed third-party attribution review and at least one external installation or review.
